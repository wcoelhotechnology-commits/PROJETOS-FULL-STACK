# Central de Comando

Aplicação web desenvolvida para organização e gerenciamento de projetos pessoais e profissionais em uma interface centralizada.

O sistema permite organizar projetos por **salas e sub-salas**, acompanhar seu progresso e visualizar suas diferentes etapas por meio de um **quadro Kanban interativo**.

## Funcionalidades

* Criação, edição e exclusão de salas
* Criação, edição e exclusão de sub-salas
* Criação, edição e exclusão de projetos
* Organização dos projetos por status
* Quadro Kanban com os estados:

  * Ideia
  * Em andamento
  * Travado
  * Pronto
* Movimentação de projetos por drag and drop
* Controle de progresso de 0% a 100%
* Definição do próximo passo de cada projeto
* Campo de anotações e contexto
* Persistência automática dos dados
* Interface responsiva para diferentes tamanhos de tela
* Modais para criação e edição dos registros

## Tecnologias

* HTML5
* CSS3
* JavaScript
* DOM API
* LocalStorage
* Drag and Drop API
* Google Fonts

## Conceitos aplicados

O projeto foi desenvolvido com foco na prática de conceitos fundamentais de desenvolvimento web, incluindo:

* Manipulação dinâmica do DOM
* Eventos e interações do usuário
* Gerenciamento de estado
* Estruturas de dados em JavaScript
* Operações de criação, leitura, atualização e exclusão (CRUD)
* Persistência de dados no navegador
* Componentização da interface por meio de funções reutilizáveis
* Design responsivo
* Organização de interfaces interativas
* Implementação de um fluxo Kanban

## Objetivo do projeto

Além de funcionar como uma ferramenta pessoal de organização, o projeto foi desenvolvido como exercício prático de desenvolvimento de aplicações web, buscando transformar conceitos de programação em uma aplicação funcional e interativa.

O projeto demonstra a capacidade de desenvolver uma interface completa no lado do cliente, implementar regras de negócio, manipular dados e criar mecanismos de persistência sem depender de um backend externo.

## Status

**Projeto funcional — versão inicial**

O projeto pode ser posteriormente expandido com autenticação de usuários, banco de dados, API REST, backend e sincronização dos dados em nuvem.
